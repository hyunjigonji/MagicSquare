## `.cursorrules` v0.1 전문 (Export 시점)

```markdown
# MagicSquare — Cursor Rules (초안 v0.1)

## 프로젝트
4×4 부분 마방진 학습 프로젝트. ECB + Dual-Track TDD. 근거: `docs/PRD.md`, `report/02.REPORT.md`.

## 도메인 (불변)
- 격자: 4×4, 값 1~16, 빈칸 `0` **정확히 2칸** (부분 격자)
- Magic constant: **34** — 10선(행4+열4+주·부대각선) 합
- 솔버 성공 출력: `int[6]` = `[r1, c1, n1, r2, c2, n2]`
  - `(r,c)`는 **1-index** 좌표, `n`은 해당 빈칸에 채울 값
- 검증 Rule: R1~R5 (`validate`) — PRD 참조

## 오류 코드 (Boundary 전용)
| 코드 | 담당 |
|------|------|
| E001~E005 | **Boundary만** — 입력·형식·범위 등 |
| E006~E007 | Boundary 또는 Control (명세에 따름) |

**Entity 금지:** E001~E005를 Entity에서 생성·처리·변환하지 않는다.

## 아키텍처 — ECB
Boundary → Control → Entity (단방향)
Entity: `entity` 패키지 외부 import 금지

## Dual-Track
Logic(entity/control): Domain Mock 금지
UI(boundary): Mock 허용

## TDD
RED → GREEN → REFACTOR
Phase / Layer / Track 선언 필수
assert 완화·skip·xfail 금지

## MagicConstant — SSOT
34, 16, 4 리터럴 산재 금지

## AI 행동
한국어, commit은 사용자 요청 시만, md 무단 수정 금지
```
