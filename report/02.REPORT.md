## 1. Executive Summary

4×4 부분 마방진 과제를 푸는 학습자는 빈칸 2개를 채운 뒤 **행·열만** 맞다고 보고 넘어가다, **마지막 검토**에서 대각선 합 불일치와 숫자 중복을 **동시에** 발견해 **약 20분**을 허비한다.

본 프로젝트의 1차 목표는 솔버·UI·ECB 전체가 아니라, **제출 전에 10선(행 4 + 열 4 + 대각선 2)과 1~16 중복을 한 번에 판정**할 수 있는지 확인하는 것이다.

## 4. 문제 정의

### 4.1 표면 문제 (금지 — 이번 프로젝트에서 하지 않을 것)

- "4×4 마방진 **검증 프로그램**을 만든다."
- "`SquareValidator`로 대각선까지 **자동 확인**해 주는 도구를 만든다."
- "ECB 구조로 **MagicSquare 솔버**를 구현한다."
- GUI, GridUI, 공유 링크, 빈칸 **자동 채우기** 솔버

### 4.2 진짜 문제 (한 문장)

> 4×4 부분 마방진 과제에서 빈칸 2개를 채운 뒤 행·열만 맞다고 보고 넘어갔다가, **마지막 검토**에서 대각선 합 불일치와 숫자 중복을 **동시에** 발견해 **20분**을 허비했다.

### 4.3 주제 한 문장 (솔루션 최소화)

> **부분 마방진을 "다 맞았다"고 착각하기 전에, 행·열·대각선(10선)과 1~16 중복을 한 번에 판정할 수 있는지 확인한다.**

## 5. R-G-I-O

| 항목 | 내용 |
|------|------|
| **Role** | 4×4 부분 마방진 과제를 푸는 **학습자** — 빈칸 2개(0)를 채운 뒤 스스로 맞는지 확인 |
| **Goal** | **채우는 중·직후**에 "행·열만 OK" 착각을 막고, **대각선 누락·숫자 중복**을 **제출 전**에 잡는다 |
| **Input** | 4×4 정수 격자 — 고정 칸 1~16, 빈칸 **0** 두 칸, 목표 합 **34** |
| **Output** | **판정 결과** — 통과 / 실패, 실패 시 **어떤 조건**인지 (행·열·대각선 합 ≠ 34, 1~16 중복·누락, 0 잔존 등) |

## 6. 성공 기준 (Mom Test 증거 연결)

| ID | 성공 기준 | 연결 증거 |
|----|-----------|-----------|
| **SC1** | **두 대각선** 합(각 34)을 검사에 반드시 포함 | "대각선 하나를 빼먹어서 20분 날렸다" |
| **SC2** | **1~16 중복·누락**을 검사에 포함 | "숫자가 겹쳤어" / "둘다야" |
| **SC3** | "마지막 검토"가 아니라 **격자 입력 직후·한 번의 실행**으로 SC1+SC2 결과 확인 | "마지막에 검토하니" + 20분 낭비 |

## 7. 도메인 규칙

| 규칙 | 설명 |
|------|------|
| **격자** | 4×4 |
| **숫자** | 1~16, 각각 1회만 (완성 시) |
| **빈칸** | 0으로 표시, 최대 2칸 |
| **목표 합** | 34 |
| **10선** | 행 4 + 열 4 + 주대각선 + 부대각선 |

### 7.1 실패 조건 (Rule — Mom Test 기반)

| Rule ID | 내용 | 증거 연결 |
|---------|------|-----------|
| **R1** | 각 **행** 합 = 34 (완성 격자 기준) | 행만 맞다고 착각 |
| **R2** | 각 **열** 합 = 34 | 동일 |
| **R3** | **주대각선·부대각선** 합 = 34 (둘 다) | 대각선 하나 누락 |
| **R4** | 1~16 **중복 없음** | 숫자 겹침 |
| **R5** | (선택) 0 없음 — 모든 칸 채움 | "채운 뒤" 검토 전제 |
