## 3. 8계층 ↔ MagicSquare 매핑 (요약)

| 계층 | MagicSquare에서의 역할 | 현재 상태 |
|------|------------------------|-----------|
| **Model** | LLM — 10선·합 34 추론 | Cursor 제공 |
| **Agent** | 파일 수정·테스트·보고서 실행 | Cursor Agent 모드 |
| **Harness** | 모드·권한·컨텍스트 실행 환경 | Cursor IDE |
| **Rule** | R1~R5, SC1~SC3, 도메인 불변식 | **`.cursorrules` v0.1** + PRD |
| **Skill** | 행→열→대각선→1~16 체크리스트 | 미작성 (PRD P2) |
| **Command** | `validate(grid)` 단일 진입점 | PRD 스케치만 |
| **Tool / MCP** | Read/Grep/Shell, pytest | Cursor 도구 |
| **Test Loop** | T1~T3 Red→Green→Refactor | 미구현 |
| **Hook** | 저장·커밋 시 자동 pytest 등 | **`hooks.json` 없음** |

**ECB vs 8계층:** 8계층 = *어떻게* 개발·검증할지(거버넌스). ECB = *앱 코드*를 entity/control/boundary로 나누는 설계 — `.cursorrules`에 방향만 명시, 구현은 STEP 4+.

## 4. `.cursorrules` v0.1 산출물

| 항목 | 내용 |
|------|------|
| **파일** | `.cursorrules` (루트, 74줄) |
| **역할** | Cursor Agent용 **Rule SSOT** — PRD·문제 정의를 코딩 세션에 주입 |
| **근거 문서** | `docs/PRD.md`, `report/02.REPORT.md` |

### 4.1 도메인 (불변)

| 항목 | 규칙 |
|------|------|
| 격자 | 4×4, 1~16, 빈칸 `0` **정확히 2칸** |
| Magic constant | **34** (10선) |
| 솔버 출력 | `int[6]` = `[r1,c1,n1,r2,c2,n2]`, 좌표 **1-index** |
| 검증 | R1~R5 — PRD `validate` 참조 |

### 4.2 오류 코드 (Boundary)

| 코드 | 담당 | Entity |
|------|------|--------|
| E001~E005 | **Boundary만** (입력·형식·범위) | **처리 금지** |
| E006~E007 | Boundary 또는 Control | 명세 후속 정의 |

### 4.3 아키텍처 · TDD

| 주제 | 규칙 |
|------|------|
| **ECB** | boundary → control → entity; Entity 외부 import 금지 |
| **Dual-Track** | Logic(entity/control) Domain Mock **금지**; UI(boundary) Mock **허용** |
| **테스트 ID** | Logic `D-*` / `test_d_*`; UI `U-*` / `test_u_*` |
| **TDD** | RED→GREEN→REFACTOR; assert 완화·skip·xfail **금지** |
| **MagicConstant SSOT** | `34`/`16`/`4` 리터럴 산재 금지 |
| **AI 행동** | 한국어; TDD 시 Phase/Layer/Track 선언; commit은 요청 시만 |

## 6. Dual-Track TDD (규칙으로 고정)

| Track | 대상 | Mock | 테스트 |
|-------|------|------|--------|
| **Logic** | entity, control | **금지** | `test_d_*`, ID `D-*` |
| **UI** | boundary | **허용** | `test_u_*`, ID `U-*` |

TDD 세션 시작 시 Agent는 반드시 선언:

```
Phase: RED | GREEN | REFACTOR
Layer: entity | control | boundary
```
